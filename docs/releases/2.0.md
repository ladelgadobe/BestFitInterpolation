# Best Fit Interpolator 2.0

Version 2.0 brings the redesigned interface, spatial diagnostics, map comparison
and updated user manual into one release. The plugin supports QGIS 3.14 onward
through the declared QGIS 4 range, using a shared Qt5/Qt6 codebase.

## Changes

- **Outlier diagnostic:** configurable IQR, MAD and optional Z tests, Global Moran,
  Local Moran/LISA classes and explicit Keep/Exclude decisions. The source layer
  stays intact; clickable help explains the parameters and spatial classes.
- **Interface:** a clean session on reopening, separate IDW/TPS controls, RF and
  residual kriging side by side, readable controls on smaller screens and a
  larger About logo. Map palettes show gradients in a settings popup; Larger
  View preserves the current colors, scale and limits.
- **Semivariograms:** MoM displays experimental observations and the fitted
  model; REML displays its theoretical curve. Changing the fitting mode refreshes
  the embedded preview. Advanced dialogs expose three-model validation,
  selection metrics and fitted parameters in Geostatistics and Framework.
- **Framework:** RF, SVM and RK can be prepared, validated and interpolated
  directly. The final summary and report identify the method that produced the
  successful output. Comparison contains aligned maps and the signed A minus B
  difference; method metrics remain in Validation.
- **Reports:** an interactive session summary, PDF export and temporary browser
  HTML with working navigation, embedded figures and collapsible sections.
- **Dense and massive data:** bounded tuning and spatial neighborhoods, block
  raster output, lightweight previews and disclosed validation strategies/sample
  counts. Automatic Global Moran retains all valid observations.
- **Compatibility:** Qt5/Qt6 and Matplotlib API adapters, restored embedded
  previews, native NumPy indices for 32-bit QGIS and Python/platform isolation of
  machine-learning dependencies. Automated discovery uses authenticated GitHub
  requests, immutable official QGIS image digests and a required compatibility gate.
- **Manual:** 48 pages with 26 current Paulínia interface screenshots, outlier
  parameters, map comparison, reports and dense/massive workflows. The original
  General Workflow is retained and the final dataset diagram follows its style.

## Manual and installation

[Open the current user manual](https://github.com/ladelgadobe/BestFitInterpolation/blob/main/BestFitInterpolator_User_Manual.pdf).
The plugin's About link uses this generic filename across releases.

Download **bestfitinterpolator.zip** from the release assets and install it through
QGIS **Plugins → Manage and Install Plugins → Install from ZIP**. Restart QGIS
after replacing an older installation. The manual is also provided as a separate
asset, alongside SHA256 checksums and the commit/file inventory.

## Verification

The required CI gate checks official QGIS images and preserved numerical
fixtures. The full matrix covers every stable QGIS 3 minor from 3.14 through 3.44
and QGIS 4.0/4.2; scheduled and release runs discover additional stable QGIS 4
minors. Native Windows checks cover QGIS 3.14.0 with 32-bit Python, 3.44.8 and
4.2.3. Numerical fixtures are preserved rather than regenerated.

See the [compatibility report](../qgis_compatibility_report.md),
[integer and ABI evidence](../integer_compatibility_20261006.md) and
[manual verification](../manual/verification.json) for measured environments and
limits. Passing these checks does not certify every distribution or future API.

Build release assets from the committed source with:

```text
python scripts/package_release.py --revision v2.0 --output-dir ../output/releases/v2.0
```

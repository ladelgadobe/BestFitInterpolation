about=Best Fit Interpolator supports spatial interpolation workflows for environmental, soil, and precision-agriculture data. The plugin compares deterministic, geostatistical, machine-learning, and hybrid approaches, including IDW, TPS, ordinary kriging, REML-assisted kriging, Random Forest, SVM, and Regression Kriging. It provides data diagnostics, semivariogram visualization, validation metrics, observed-vs-predicted plots, interpolation maps, and a framework-guided decision workflow based on: Delgado Bejarano, L., Loureiro Goncalves Oliveira, A., Fiolo Pozzuto, J. V., Castaneda Sanchez, D., and Rios do Amaral, L. (2026). Performance of interpolation methods in digital soil mapping: the influence of data characteristics. Precision Agriculture, 27(1), 10. https://doi.org/10.1007/s11119-025-10311-8. Contact: ladelgadobe@unal.edu.co. LinkedIn: Laura Delgado Bejarano - https://www.linkedin.com/in/laura-delgado-bejarano-09b6681a2/; Lucas Rios do Amaral - https://www.linkedin.com/in/lucas-rios-do-amaral-bb302449/.
changelog=Version 1.2: Enables Framework to prepare, validate, and interpolate with Random Forest, SVM, and Regression Kriging without requiring a prior run from their individual pages; fixes Framework controller iface wiring and RFE dispatch by routing RFE directly through the RF backend; keeps SVM validation aligned with the SVM interpolation pipeline and uses shared Framework observed-vs-predicted axes plus observed-value map color limits for RF/SVM previews; classifies runtime as normal up to 500 valid samples, dense from 501 to 10,000, and massive/productivity-scale above 10,000 with a visible Data-tab profile info popup; validates Framework method comparisons above 10,000 valid samples with a reproducible spatial hold-out of up to 10,000 test points while final fitting/interpolation keeps the available valid samples; uses rasterized scatter or hexbin point maps for large displays; keeps Moran's I on all valid samples with k=8 and adaptive permutation counts, replacing dense KNN distance matrices with blockwise spatial neighbor search and exact-result caching instead of sample-based approximation; lets the Geostatistics semivariogram be visualized either by lag distance or by requested number of lags; recomputes Geostatistics model-validation results before opening the dialog and shows only metric columns; adds a visual Map comparison tab for two loaded/generated raster maps; adds a Matplotlib Qt backend fallback for older QGIS 3.x installations; activates the massive productivity-data profile above 10,000 samples with RF capped at 300 trees and minimum leaf size 5, SVM using 128 Nyström components, ML validation using a reproducible hold-out split, semivariograms using fewer legible lags, and IDW/Moran/variogram stages avoiding dense pairwise distance matrices; blocks Data and Framework diagnostics early with a CRS alert when point and polygon layers do not share the same CRS; stabilizes TPS with scaled coordinates and observed-range clipping on the final map and validation folds; writes RF/SVM/RK rasters by blocks with tiled/BigTIFF GeoTIFF output and lightweight large-grid previews; marks RF/SVM/RK interpolation as complete only after the raster is created and loaded; bounds TPS, kriging neighborhoods, IDW/RF/SVM/RK prediction chunks, and records dense-method disclosures in raster metadata without interrupting interpolation with dense-profile alerts. Version 1.1 synchronized the Framework semivariogram preview with the active Geostatistics model; blocked interpolation for incompatible CRS or unusable spatial overlap; improved popup notifications; fixed deterministic TPS routing and the REML prediction matrix error; standardized R² labels; and added the metadata-driven About tab.

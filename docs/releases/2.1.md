# Best Fit Interpolator 2.1

Version 2.1 adds translated interfaces, conditional and diagnostic uncertainty
maps, automatic Framework ML searches and independent execution state.

## Changes

- Offline English, Spanish and Brazilian Portuguese interface with a saved language selector, translated dialogs, plots and new reports.
- Ordinary and linear Universal Kriging with conditional SD/variance maps; joint constrained weighted least-squares MoM fitting and explicit model-scale/practical-range conventions.
- RF tree-dispersion maps and RK conditional residual-kriging uncertainty, with an optional Add SD layer control for standalone and Framework runs.
- Automatic bounded RF/SVM/RK grid search in Framework using the individual workflows' routines and defaults, configurable budgets, exact-input cache reuse and report provenance.
- Independent Framework and standalone maps, models, metrics and SD choices; Framework previews stay empty until a successful Framework interpolation.
- Independent raster-file predictor readers, coverage accounting, responsive validation with cancellation and hidden Windows helper processes.
- Reports distinguish initial recommendations, validation winners, next selections and actual executions, and display the complete map comparison at the report width.
- Updated 51-page English manual, retaining its stable filename and the original Auto, LOOCV and K-Fold validation workflow.

## Uncertainty and validation

Kriging SD and variance are conditional on the fitted model. RF tree SD measures
tree disagreement, not a calibrated prediction interval or the standard error
of the forest mean. RK residual-kriging SD excludes trend and variogram-parameter
uncertainty; RF trend spread is shown separately and is not added to a total RK
variance. See [component definitions](../../bestfitinterpolator/UNCERTAINTY_RF_RK.md).

Framework uses the same bounded, reproducible finite-grid sampling as the
individual RF/SVM/RK windows, with default budgets of 10/12/10 combinations and
three search folds. The report records the actual search and selected parameters.
Auto, LOOCV and K-Fold validation remain available. Spatial block validation is
deferred and is not included in this version.

## Manual and package

The 51-page [user manual](../../BestFitInterpolator_User_Manual.pdf) retains the
repository-root filename `BestFitInterpolator_User_Manual.pdf`. This preserves
the URL used by the plugin. Editable source is in [docs/manual](../manual).

The source and manual are updated in GitHub. The installable ZIP, manual,
manifest and checksums are prepared as a draft GitHub Release. Publishing that
Release is a separate step because this repository has an active Zenodo hook.
QGIS repository submission is also a later step.

Build the package from the committed source:

```text
python scripts/package_release.py --revision HEAD --output-dir ../output/releases/v2.1
```

## Verification

The tested candidate passed 197 unit tests and targeted real-QGIS regressions on
Windows QGIS 3.44.8 and 4.2.3, including all six Framework methods, numerical
parity with the preceding candidate, independent workflow results, uncertainty
layer choices, report recommendation provenance and map comparison layout.
The production Python source is unchanged from that tested candidate apart from
Git's line-ending normalization; its parsed syntax trees are identical. Release
metadata and explanatory documentation are refreshed separately.

The original version 2.0 numerical fixture is retained. Intentional changes to
automatic ordinary semivariogram fits are checked against analytic synthetic
curves and an independent SciPy least-squares reference; unaffected fixture
outputs continue to be compared to the original values. GitHub's required
compatibility gate must pass before this update is merged. See the PR checks
for the measured v2.1 environments; historical v2.0 coverage is not a claim that
all platforms have already been rechecked for v2.1.
